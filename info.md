# Dreame Wet & Dry Vacuum

Unofficial Home Assistant integration for Dreame wet and dry vacuums. Includes model-aware status, controls, alerts, maintenance entities, and an optional Lovelace dashboard card.

H14 mappings remain on their existing path. H15 Pro Heat support is experimental and its sensor mapping is incomplete; unknown values are not guessed. Review the README and H15 mapping notes before enabling controls. Physical device testing is still in progress.
