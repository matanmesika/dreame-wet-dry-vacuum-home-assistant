# Security policy

## Supported versions

Security fixes are developed against the current default branch. There is no stable release series while the H15 mapping work is in progress.

## Reporting a vulnerability

Please report suspected security vulnerabilities through GitHub's **Report a vulnerability** action for this repository, which opens a private security advisory. If private reporting is unavailable, contact the repository maintainers through their GitHub profiles and do not publish credentials, tokens, personal data, or an exploit before maintainers have had a chance to respond.

This integration handles Dreame account credentials and cloud access tokens. Never attach unredacted diagnostics, configuration-entry storage, account credentials, or access tokens to a public issue.
