# Dreame Wet & Dry Dashboard

A theme-aware Home Assistant Lovelace card for supported Dreame wet & dry vacuums. Three tabs cover **Operation**, **Device status**, and **Maintenance**, using real Home Assistant entities only. English and Hebrew UI are available.

**Preview only.** H15 Pro Heat mappings remain experimental; several commands and device alerts need physical verification. See the [README](README.md) for installation, [current H15 card UI](docs/CURRENT_UI.md), safeguards, and known limitations.
