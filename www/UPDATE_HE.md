# חבילת ניסוי — מיפוי לפי סוג מכשיר והתנהגות האפליקציה

מספר הגרסה נשאר ללא שינוי. המיפוי עדיין אינו סופי ולא נבדק כאן במכשיר פיזי. תיקון נוסף בחבילה זו מוסיף DID לכל שורת קריאה וכתיבה, ומנרמל ערכי `get_properties` שמגיעים כמחרוזות לפני פענוח המצבים. הוא נועד למנוע מצבים שבהם משוב תקין מהשרת מוצג כ־unknown.

1. החלף את התיקייה `custom_components/dreame_wet_dry_vacuum` מתוך החבילה בתיקיית `config/custom_components/`. אין צורך למחוק את התקנת האינטגרציה.
2. העתק את `www/dreame-device-card.js` אל `homeassistant/www/community/Dreame-device-card/`.
3. הפעל מחדש את Home Assistant. במשאבי הדשבורד עדכן את המשאב הקיים, מסוג JavaScript module:

```text
/local/community/Dreame-device-card/dreame-device-card.js?test=maintenance-fallback
```

4. סגור ופתח את האפליקציה או רענן את הדפדפן. בעורך הכרטיס בחר Device type: H15 ומכשיר H15 Pro Heat. עבור H14 בחר H14. הזיהוי מתבסס על רשומות האינטגרציה, גם אם שמות הישויות שונו. כשיש כמה מכשירים בחר אחד במפורש.

```yaml
type: custom:dreame-device-card
model: H15
language: en
title: H15 Pro Heat
```

בחירות ידניות קודמות נשמרות. כדי לחזור לזיהוי האוטומטי, הסר את `entities` מתצורת הכרטיס או בחר Automatic לכל חיווי. שינוי סוג המכשיר בעורך מאפס את הבחירות הידניות כדי שלא לערבב פקדי H14 ו־H15.

## השינויים ובדיקת הניסוי

- שלוש לשוניות: תפעול, מצב המכשיר ותחזוקה. צבעים ושטח הכרטיס יורשים את ערכת הנושא.
- אין יצירת חיישן לכל שדה שהסריקה מוצאת. ישויות H15 מיותרות מההתקנה הישנה מושבתות בהעברה חד פעמית; ההיסטוריה אינה נמחקת. רשימת כלל הישויות עשויה עדיין להציג רשומות מושבתות. חומר הגלם נשמר בייצוא המיפוי.
- מצבי שטיפה/ייבוש נשלחים יחד עם ההעדפה הנלווית, בהתאם לקוד האפליקציה. אם ההעדפה חסרה, העירו את המכשיר ובצעו Refresh mapping snapshot; אין ניחוש של הערך.
- הפעילו Custom mode ובחרו Personalized כדי לשנות שאיבה וכמות מים. כשהחימום פועל, השאיבה האישית קבועה ל־Gentle; בחירת Quiet/Turbo אפשרית לפי האפליקציה.
- ווליום הוא סליידר של שלוש רמות 0/1/2, הנשלחות כ־0/30/60. בדקו כל רמה מול הצליל והאפליקציה.
- יתרת פילטר ומברשת מוצגת באחוזים רק כשיש אורך חיים מרבי מאומת. אם האחוז לא ניתן לחישוב, הכרטיס מציג את זמן היתרה שהחיישן מדווח בשעות, ומציין שהאחוז חסר. זמן היתרה אינו מפעיל התראת תחזוקה.
- תחזוקה כוללת התראות מיכלים ותקלות מפוענחות. בצילומי השרת שסיפקת, 4.6 השתנה מ־0 ל־81 יחד עם שגיאת מיכל מים מלוכלכים מלא (`4.2=4096`) וההתראה באפליקציה. הוא נשאר מועמד למצב המיכל, ללא אחוז, עד שנראה חזרה ל־0 לאחר הריקון. 4.5 ו־4.7 לא השתנו ולכן אינם משמשים למיפוי מים נקיים או שאיבה.
- בדקו גלילה בזמן עדכון נתונים, כיוון חצים באנגלית, זיהוי אוטומטי ועדכון מצב לאחר שינוי באפליקציה.
