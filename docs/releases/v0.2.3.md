## Dreame Wet & Dry Vacuum v0.2.3 (stable)

The stable release of the 0.2.3 line for the H15 Pro Heat and H14. It contains everything from v0.2.3-beta.2:

- Cleaning Record sensors from the Dreamehome app (cleaning time today / 7 days / 30 days with the dirt-level split, sessions in the last 7 days, last cleaning).
- Firmware update entity (read-only; installing stays in the Dreamehome app).
- Settings cache: the last known app settings survive Home Assistant restarts.
- Option names match the Dreamehome app. Automations that compare option texts need the new names.
- The generic `vacuum` entity is removed; the dedicated controls cover everything it did.

**Changed since the beta**
- MIT license.
- README gallery shows the current Dreame Device Card.
- Removed the old copies of the dashboard card from this repository. The card now lives in [matanmesika/dreame-device-card](https://github.com/matanmesika/dreame-device-card) (v1.2.0 or newer).

No changes to the integration code since v0.2.3-beta.2.
